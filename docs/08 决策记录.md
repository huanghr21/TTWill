## 开工前补充决策

| 补充 | 已确认结论 | 主文档 |
| --- | --- | --- |
| 短确认的范围 | 单个展示操作可用明确的简短同意直接确认；多个操作逐项判定，明确“全部确认”才整体提交，范围不明继续追问 | [02 · 确认与提交](<02 Agent架构设计.md#确认与提交>) |
| 条件备用任务的终止 | 条件分支不再需要时，由协调者提出撤销，代码记录原因并视为终止状态，不计为失败；条件判断仍由模型负责 | [02 · 协调者与任务状态](<02 Agent架构设计.md#协调者与任务状态>) |
| 准备阶段的断点恢复 | 关联标识由代码按 `task_id + revision + 动作类型` 确定性生成；重试与恢复沿用，任务请求内容修改或失效操作需重新准备为新请求时递增修订号。覆盖“准备成功但操作 ID 未写入检查点”的窗口，恢复时重算标识找回或清理操作；不要求每次准备前保存检查点或拆图节点，不新增任务状态副本 | [02 · 跨会话续办](<02 Agent架构设计.md#跨会话续办>)、[05 · 第一部分：项目本体](<05 实施计划.md#第一部分项目本体>) |
